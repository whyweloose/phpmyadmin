## About

This is an independent fork of [phpMyAdmin](https://www.phpmyadmin.net/), maintained by **[whyweloose](https://github.com/whyweloose)**.

The fork focuses on refreshing the interface with an **iOS-inspired design**, bringing a new visual style to the familiar phpMyAdmin experience.

> **Note:** This is an unofficial fork, not an official phpMyAdmin release or an Apple-affiliated project.

## Fork Changes

### iOS-Inspired Redesign

- Redesigned the interface in an **iOS-inspired style**.
- Shifted the visual direction toward a clean, modern appearance.

The primary change in this fork is the **interface design**.

## Installation

To use the redesigned version, clone or download **this fork**, rather than the upstream release.

phpMyAdmin uses [Composer](https://getcomposer.org/) to manage PHP dependencies. When installing from a Git checkout, you must install dependencies manually.

See the [installation-from-Git guide](https://docs.phpmyadmin.net/en/latest/setup.html#installing-from-git) for detailed setup instructions and requirements.

### Official Upstream Downloads

Official phpMyAdmin releases are available at **[phpmyadmin.net](https://www.phpmyadmin.net/)**.

These releases do **not** include this fork’s redesign.

The upstream repository uses the following branch and tag conventions:

| Branch or tag | Description |
| :--- | :--- |
| `STABLE` | Current stable release |
| `master` | Development branch |
| `RELEASE_5_0_1` | Example release tag for version 5.0.1 |
